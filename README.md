# ✈️ 2026 오사카·교토 4박 5일 미식 & 힐링 가이드 웹페이지

2026년 10월 31일(토) ~ 11월 4일(수) 오사카·교토 여행을 위한 반응형 인터랙티브 가이드 웹 애플리케이션입니다.

## 🌟 주요 기능

1. **실시간 D-Day 카운트다운 타이머**: 출발일(2026.10.31 16:35 KIX)까지 남은 일/시/분/초 실시간 표시
2. **인터랙티브 일자별 타임라인 (Day 1 ~ Day 5)**:
   - 날짜별 탭 전환 및 전체 일정 일괄 보기 지원
   - 시간대별 세부 동선, 소요 시간, 교통 수단, 구글 지도 링크 및 꿀팁 제공
3. **5대 핵심 미식 & 맛집 마스터 가이드**:
   - 1일차 와규 야키니쿠 (마츠자카규 M 호젠지요코초점)
   - 2일차 숯불 장어덮밥 (우나기시로 키쿠카와 교토기온점) & 쿠시카츠 다루마
   - 3일차 와규 스키야키 (와규 스키야키 치카라야마 난바 1호점)
   - 4일차 구로몬 시장 해산물 & 프리미엄 테판야키 (고베규 스테이크 진 난바점)
   - 식당 상세 모달 팝업, 구글 평점, 대표 메뉴, 가격대, 예약 링크 연동
4. **교통편 & 패스 가이드**:
   - 난카이 특급 라피트 (KIX ↔ 난바) 시간표 및 예매법
   - 게이한 본선 특급 교토 당일치기 이용법
   - USJ 난바 환승 루트 (한신 + JR) 및 IC 카드 팁
5. **인터랙티브 예산 시뮬레이터**:
   - 인원수(1인/2인/N인) 및 환율 실시간 반영
   - 항목별(항공, 숙박, 교통, 관광, 식비, 쇼핑, 기타) 금액 수정 및 원화(KRW) 자동 환산
6. **여행 준비물 체크리스트**:
   - 필수 서류, 금융/환전, 전자기기, 사전 예약, 의류/용품, 비상약
   - 체크 상태 브라우저(LocalStorage) 자동 저장 및 실시간 진행률(Progress Bar) 연동

## 🚀 로컬 실행 방법

별도의 복잡한 빌드 과정 없이 정적 웹 서버로 즉시 구동 가능합니다:

```bash
# Python 내장 웹 서버 실행 (포트 3000)
python3 -m http.server 3000
```

브라우저에서 `http://localhost:3000`에 접속하여 확인할 수 있습니다.
